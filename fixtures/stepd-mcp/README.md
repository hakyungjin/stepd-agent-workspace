# STEP D MCP 응답 형식 fixture

`lib/stepd/mcp-text.ts` 파서를 고정하는 계약 테스트 입력입니다. 서버 문구가 바뀌면 카드가 조용히 틀리는 대신 `tests/mcp-contract.test.ts`가 먼저 깨집니다.

## ⚠️ 내용은 전부 가상입니다

작품명·인물명·대사·회차 요약·편집본 제목·식별자(`p_`·`m_`·`c_`·`e_`·`cast_`)·주소는 **모두 지어낸 것**입니다. 실제 방송 내용도, 실제 워크스페이스 데이터도 아닙니다.

검증 대상은 **내용이 아니라 형식**입니다 — 줄 구조, 필드 이름, 선택 필드의 유무, 구분자, 숫자 표기. 그래서 가상 내용으로도 파서를 똑같이 고정할 수 있습니다.

실제 서버 응답을 공개 저장소에 두지 않는 이유: 방송 대사 원문과 회차 줄거리는 권리 확인 전 자료이고(응답 자신이 `출연자 권리 확인필요`라고 적습니다), 작품 목록·내부 식별자는 워크스페이스 데이터입니다.

## 정본은 샘플이 아니라 생성 코드입니다

파서는 응답을 **만드는 코드**를 읽고 작성했습니다(`STEPD-repo/packages/mcp`):

| 생성 코드                  | 담당 출력                                                        |
| -------------------------- | ---------------------------------------------------------------- |
| `src/tools/scene-format.ts` | `sceneBlock` · `castLabel` · `rightsLine` · `clock` · `splitCast` |
| `src/tools/understand.ts`   | `get_program_overview` · `get_episode_outline` · `rightsOf`      |
| `src/tools/clip-format.ts`  | `clipBlock`                                                      |
| `src/tools/common.ts`       | `get_credit_balance` · `get_queue_status` · `list_clips`          |
| `src/tools/ask.ts`          | 꼬리에 붙는 `· 질문` 블록                                        |

샘플만 봤을 때 놓쳤던 것들이 여기서 드러났습니다 — 스포일러 표시가 `권리:` 줄 안에 있고, `clock()`이 1시간을 넘기면 `h:mm:ss`이고, `castLabel`이 한 인물 안에 ` · `를 넣고, 방영일·장면유형·훅·권리·대사 줄이 **각각** 선택이라는 점입니다.

## 파일과 재현하는 분기

| 파일                   | 재현하는 것                                                                               |
| ---------------------- | ----------------------------------------------------------------------------------------- |
| `program-list.txt`     | 목록 모드 · 장르/회차/편집본 칸이 없는 작품 · 대괄호·쉼표 들어간 제목                     |
| `program-overview.txt` | 상세 모드 · `(done)`과 `analyze(progress)` 혼재 · 방영일 없는 회차 · `회차 번호 없음`     |
| `search-scenes.txt`    | 검색 히트 3건 · 화면 인물/말한 사람 분리 · 화자 표기된 대사                               |
| `episode-outline.txt`  | 서사 → 사건 흐름 → 핵심 갈등 → 장면 · 상세 없는 구간 · 권리 줄 속 스포일러 · 대사 없는 장면 |
| `list-clips.txt`       | 편집본 목록 · `제목 없음` · 재인코딩 경고 · 배포 이력 있음/없음 · 종류 줄 없음            |
| `edge-cases.txt`       | 1시간+ 타임코드 · 별칭 묶음 속 ` · ` · `이름 미확인 N명` · `회차 이름 없음` · `일치도 ?` · 권리 줄 없음 · 권리 확인됨 |

## 서버 버전에 대해

실제 호출로 계약을 확인한 시점에 **배포된 서버가 로컬 소스보다 구버전**이었습니다:

| 무엇          | 배포본                | 로컬 소스                                 |
| ------------- | --------------------- | ----------------------------------------- |
| 인코딩 상태   | `구워짐`              | `인코딩 완료` / `⚠️ 재인코딩 필요`        |
| 대기열 라우트 | 403 `superadmin only` | `/queue/mine`(2026-10-07 수정) — 403 없음 |

파서는 두 문구를 모두 견딥니다(인코딩 문구는 읽지 않고, 대기열 403은 미연결로 처리).

## 도구가 없어서 못 쓰는 것

- `create_clip_draft` — 이 서버에 **없는 도구**입니다. 쓰기 도구는 `edit_captions`·`rerender_clip`·`set_shorts_title`·`set_channel_metadata`뿐이고 모두 기존 편집본을 변경합니다. 변경 도구는 gateway에 연결하지 않았습니다.
